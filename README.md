# Codex Evades

This is a simple prototype for an online multiplayer bullet-hell survival game inspired by **Evades**.

The project uses **Node.js**, **Express** and **socket.io** for networking and a basic HTML5 canvas client.

## Running the Game

Install dependencies:

```bash
npm install
```

Start the server:

```bash
node server.js
```

Open [http://localhost:3000](http://localhost:3000) in your browser. Open the page in multiple tabs or share your local address to play with others on the same network.

## Description

This prototype demonstrates a very small subset of the features described in the game guide. Multiple players can connect, move around, and avoid randomly moving red squares. This is only a starting point for building the full game.
